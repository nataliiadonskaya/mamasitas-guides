Источники: [ст. 160 RD 1155/2024](https://www.boe.es/buscar/act.php?id=BOE-A-2024-24099), [Hoja 42](https://inclusion.gob.es/web/migraciones/w/51.-residencia-de-larga-duracion-en-espana-del-residente-de-larga-duracion-ue-en-otro-eemm-de-la-ue-duplicar-0-4), [Orden PJC/617/2025](https://www.boe.es/buscar/doc.php?id=BOE-A-2025-12056).
:::

## Что это за процедура

**Autorización de residencia** для ребёнка (или лица с discapacidad), который **не родился в Испании**, но уже живёт здесь с родителем или опекуном‑резидентом. Виза не нужна: ребёнок уже в стране.

| Параметр | Значение |
| --- | --- |
| Норма | ст. 160 RD 1155/2024 |
| Бланк | EX-25 |
| Tasa | **790-052**, epígrafe **2.1.5**, **10,94 €** |
| Срок карты | **5 лет** |
| Срок решения | **1 месяц**; молчание = отказ |

Это **не** reagrupación familiar (та — если ребёнок ещё за границей и нужен visado) и **не** ст. 159 (ребёнок, **рождённый в Испании**).

## Кто может получить

Подаёт **отец, мать или tutor** с residencia по регламенту. Можно подать, даже если residencia родителя **ещё в процессе**.

Подходит, если на дату подачи:

- ребёнок **младше 18** (или совершеннолетний сын/дочь с discapacidad, который объективно не может содержать себя);
- **не родился в Испании**;
- живёт с родителем / опекуном‑резидентом;
- **не создал собственную семью**.

Граждане ЕС / ЕЭЗ / Швейцарии и их семейный режим — не этот маршрут.

## Требования

1. **2 года** непрерывного пребывания ребёнка в Испании до даты подачи.
2. **Средства и жильё** как для reagrupación familiar (ст. 67): ориентир — 150 % IPREM на двоих (родитель + ребёнок) и ещё 50 % IPREM на каждого следующего члена семьи; жильё — обычно informe de adecuación de vivienda.
3. Школьный возраст — **matrícula** в официальном центре + декларация escolarización.
4. Если ребёнок только одного из супругов / пары: **patria potestad** у подающего **или** согласие второго родителя / судебное разрешение на переезд.

:::tip[Согласие второго родителя]
Hoja 42 почти всегда просит **declaración / autorización** второго родителя, чтобы ребёнок жил в Испании. Исключения: **исключительная опека** у подающего или **разрешение суда** — тогда кладите эти документы вместо согласия.
:::

Для семей с **временной защитой** по Украине отдельные инструкции SEM 2/2026 могут снимать 2 года, средства и жильё. Если это ваш случай — уточните в офисе и приложите ссылку на инструкцию.

## Документы

Копии + оригиналы на показ. Иностранные акты: перевод jurado и apostilla / legalización.

1. **EX-25**, подписанный родителем или tutor.
2. Полный **паспорт** ребёнка **и** подающего родителя (или cédula / documento de viaje).
3. **Свидетельство о рождении** ребёнка (или документы опеки).
4. **Согласие второго родителя** (или exclusive custody / resolución judicial).
5. Доказательства **2 лет** в Испании (padrón, школа, медицинские карты, TIE / resguardo, stamps — что примет ваш офис).
6. Средства (nóminas, IRPF, prestación, декларации) и **жильё**.
7. Школа + декларация escolarización, если возраст обязательный.
8. При discapacidad — подтверждающие документы.
9. **Объединённый PDF**: заявление + документы + **подтверждение оплаты tasas**.

## Объединённый PDF с подтверждением оплаты

Офисы Mercurio / sede лучше принимают **один** файл, чем россыпь сканов.

Рекомендуемый порядок страниц:

1. EX-25.
2. Justificante **790-052**, пункт **2.1.5** (NRC виден).
3. Паспорта.
4. Acta de nacimiento.
5. Согласие второго родителя (или судебные / опекунские бумаги).
6. Padrón и доказательства 2 лет.
7. Школа.
8. Средства и жильё.

Имя файла, например: `EX25_Apellido_NIE_menor.pdf`. Качество читаемое, без обрезанных краёв NRC.

## Tasa 052, пункт 2.1.5

| Поле | Что ставить |
| --- | --- |
| Модель | 790, код **052** |
| Epígrafe | **2.1.5** Residencia temporal de menores extranjeros acompañados |
| Сумма | **10,94 €** |
| Кто платит | родитель / tutor (субъект — в пользу ребёнка) |
| Когда | при подаче; по электронной подаче — **в момент** отправки |

1. [Модель 790-052](https://sede.administracionespublicas.gob.es/pagina/index/directorio/tasa052).
2. Provincia офиса ребёнка.
3. Данные плательщика (NIE родителя).
4. Epígrafe **2.1.5**, не 2.1.2 (reagrupación) и не 2.3.x (arraigo).
5. Оплата → PDF с NRC → **сразу в объединённый PDF**.

После концессии отдельно платится **TIE: 790-012** (обычно первая карта residencia temporal — **16,08 €**). См. [справочник tasas](/reference/tasas/).

## Как заполнить EX-25

1. Данные **ребёнка** (titular будущей карточки): имя как в паспорте, дата рождения, гражданство, NIE если уже есть.
2. Данные **подающего родителя**: NIE, тип своей residencia, адрес, где живёт ребёнок.
3. Тип: residencia del menor acompañado / ст. 160 (формулировка на бланке).
4. Подпись родителя или tutor — не самого ребёнка, если он несовершеннолетний.

## Подача и сроки

- Лично: Oficina de Extranjería провинции **адреса ребёнка**, cita previa.
- Электронно: sede Ministerio de Política Territorial с сертификатом родителя или через abogado / gestor / graduado social. Канал Mercurio уточните в своём офисе.

Срок решения — **1 месяц**. Если чего‑то не хватает, придёт **requerimiento на 10 дней**, иначе archivo.

После одобрения: **TIE** лично, ребёнок **с одним из родителей**, в течение **1 месяца**. С 16 лет (возраст труда) карта **сама** даёт право работать, без отдельного разрешения.

## Чеклист

- [ ] Ребёнку нет 18 на день подачи (или есть документы discapacidad)
- [ ] 2 года пребывания подтверждены **или** ваш особый режим (PT) это снимает
- [ ] EX-25 подписан родителем
- [ ] Согласие второго родителя **или** exclusive custody / суд
- [ ] Tasa **052 2.1.5 = 10,94 €** оплачена
- [ ] Justificante вшит в **один PDF** вместе с пакетом
- [ ] Школа, средства, жильё — если требуются в вашем сценарии
