## 📌 Як користуватися результатом

1. Виберіть категорію.
2. Виберіть конкретну процедуру в другому списку.
3. Якщо з’явиться додаткове запитання про зарплату, виберіть відповідний варіант.
4. Перевірте опис тарифу та інформацію про те, хто повинен його сплачувати.
5. Відкрийте офіційну інструкцію та звірте суму перед оплатою.

## ⚠️ Важливо

- Modelo 790 código 052 призначена для зборів за проживання та відповідну документацію.
- Modelo 790 código 062 використовується для зборів за дозволи на роботу.
- Для первинного дозволу, модифікації, продовження та переходу з тимчасового захисту можуть застосовуватися різні підстави й тарифи.
- Для оформлення TIE може знадобитися Modelo 790 código 012. Цей калькулятор не розраховує збір 012.
- Не сплачуйте збір за аналогією зі схожою процедурою.
