## 📌 Как пользоваться результатом

1. Выберите категорию.
2. Выберите конкретную процедуру во втором списке.
3. Если появится дополнительный вопрос о зарплате, выберите подходящий вариант.
4. Проверьте описание тарифа и кто должен его оплачивать.
5. Откройте официальную инструкцию и сверьте сумму перед оплатой.

## ⚠️ Важно

- Modelo 790 código 052 предназначена для пошлин за резиденцию и соответствующую документацию.
- Modelo 790 código 062 используется для пошлин за разрешения на работу.
- При первоначальном разрешении, модификации, продлении и переходе с временной защиты могут применяться разные основания и тарифы.
- Для оформления TIE может требоваться Modelo 790 código 012. Этот калькулятор не рассчитывает пошлину 012.
- Не оплачивайте пошлину по аналогии с похожей процедурой.
