<script is:inline>{`
  function updateCalc() {
    const val = document.getElementById('procedure').value;
    const res052 = document.getElementById('res-052');
    const res062 = document.getElementById('res-062');
    const card062 = document.getElementById('card-062');

    if (val === 'autonomo') {
      res052.innerText = '€10.94';
      res062.innerText = '€203.84';
      card062.style.display = 'block';
    } else if (val === 'cuenta-ajena') {
      res052.innerText = '€10.94';
      res062.innerText = 'Оплачивает работодатель (€203.84)';
      card062.style.display = 'block';
    } else if (val === 'menores') {
      res052.innerText = '€10.94';
      card062.style.display = 'none';
    }
  }
`}</script>

## 📌 Заполнение и сборка квитанций

При подаче документов через систему **Mercurio** квитанции и чеки об оплате загружаются **в едином PDF-файле**.

1. **Оплатите квитанции:** В банкомате или онлайн-банкинге (BBVA, CaixaBank, Santander).
2. **Получите NRC:** Сохраните квитанцию с кодом подтверждения оплаты (Número de Referencia Completo).
3. **Объедините документы:** Бланки Modelo 790 + чеки оплаты скрепляются в один общий PDF.
